# AR CRAZYGAMES SEO setup

## Production domain
- Site: https://arcrazygames.site/
- Sitemap: https://arcrazygames.site/sitemap.xml
- Robots: https://arcrazygames.site/robots.txt

## Included
- Homepage title, description, canonical, Open Graph, Twitter and JSON-LD metadata.
- English, French, Arabic, Spanish, German and Chinese localized metadata.
- Language query support using `?lang=en`, `?lang=fr`, `?lang=ar`, `?lang=es`, `?lang=de`, and `?lang=zh`.
- hreflang alternates for the supported languages.
- Crawlable category pages and game URLs.
- Updated sitemap and robots.txt for the new domain.
- No advertising placeholders or reserved ad areas in the catalog/category layout.

## Before publishing
1. Set the custom domain in GitHub Pages to `arcrazygames.site`.
2. Confirm DNS records point to GitHub Pages.
3. Publish this build.
4. Verify `https://arcrazygames.site/robots.txt` and `https://arcrazygames.site/sitemap.xml`.
5. Add the domain to Google Search Console and submit the sitemap.
